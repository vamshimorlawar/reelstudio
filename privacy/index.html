Privacy Policy

Last updated 27 October 2026

Reel Studio

Reel Studio is a personal tool that runs on its user's own computer. It is not a hosted service and has no accounts or servers of its own. Everything it makes and every key or sign-in it uses is stored only on that computer.

YouTube and Google

Reel Studio uses YouTube API Services, only to upload videos to the user's own YouTube channel and to read that channel's name. It does not collect, store or share data about anyone else. Google sign-in tokens are stored only on the user's computer and are never sent anywhere except Google. See the Google Privacy Policy and the YouTube Terms of Service. Access can be revoked at any time at myaccount.google.com/permissions.

Other services it calls

To make videos, Reel Studio sends requests from the user's computer to services the user has set up with their own keys: an AI writer (Anthropic Claude or Google Gemini) for script text, Pixabay for stock footage and photos, and Google Trends, Wikipedia and YouTube for topic research. Only the text needed for each request is sent.

This website

This site has no cookies, no analytics, no trackers and no third-party fonts or scripts. We don't collect personal information when you visit.
